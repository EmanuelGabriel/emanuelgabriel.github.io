Sobre Mim

Engenharia de software com foco em resultados

Sou Programador de Sistemas de Informação Sênior na Totem TI, com formação superior completa e especialização em tecnologia. Atuo no desenvolvimento de sistemas enterprise utilizando Java, Spring Boot, Angular e todo o ecossistema JakartaEE.

Minha trajetória profissional foi construída com dedicação e resiliência. Desde os primeiros trabalhos na adolescência até me tornar um profissional sênior, cada experiência contribuiu para formar minha visão técnica e comprometimento com a qualidade do código entregue.

Tenho sólida experiência com desenvolvimento full stack, desde a modelagem de banco de dados e criação de APIs RESTful com Spring Boot e JPA/Hibernate, até a construção de interfaces modernas com Angular, JSF e PrimeFaces. Trabalho com Docker para containerização, Git para versionamento e bancos como PostgreSQL, MongoDB e SQL Server.
